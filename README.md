# 穿了没

用来记录每件衣服穿了多少次的本地优先 PWA。首版支持衣物导入、相机拍照识别、当天日期校验、上衣/裤子/鞋组合预览、历史周期统计和单件衣物数据。

## 功能

- 衣橱导入：添加上衣、裤子、鞋，保存名称、品牌、备注、主色和衣物照片。
- 拍照记录：打开浏览器相机拍照，校验记录日期是否为本地当天。
- 自动识别：基于导入照片生成本地图片特征，拍照后按上衣、裤子、鞋给出识别候选并可确认。
- 历史周期：支持 7 天、30 天、90 天、今年、全部、自定义周期统计。
- 单件衣物：展示每件衣物总次数、最近穿着日期和穿着历史。
- 组合效果：选择上衣、裤子、鞋查看组合预览，并统计周期内常穿组合。
- 数据迁移：支持 JSON 导入/导出，数据保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev
```

构建与自测：

```bash
npm run build
npm run test
npm run lint
```

相机 API 需要安全上下文，开发时使用 `localhost`，部署后使用 `https` 域名。

## 首版边界

当前识别是纯浏览器本地算法，使用颜色直方图和平均颜色做相似度匹配，不上传照片，也不依赖云端模型。它适合快速可用的 MVP，后续可以替换为 TensorFlow.js、MediaPipe 或服务端视觉模型。
