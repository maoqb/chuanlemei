# 需求矩阵

| 编号 | 用户诉求 | 首版交付 | 验收方式 | 状态 |
| --- | --- | --- | --- | --- |
| R1 | 在 GitHub 新建源码仓库 | 仓库名 `chuanlemei`，推送完整 React/Vite/PWA 源码 | 访问 GitHub 远程仓库 | 已实现 |
| R2 | 记录每个衣服穿了多少次 | 每条穿着记录保存关联衣物，统计总次数和周期次数 | 单件衣物数据面板、衣物排行 | 已实现 |
| R3 | 支持看历史周期的数据 | 提供 7 天、30 天、90 天、今年、全部、自定义周期 | 统计页切换周期 | 已实现 |
| R4 | 支持看每件衣服的数据 | 侧边栏展示所选衣物总次数、最近日期、历史记录 | 选择衣橱卡片或排行项 | 已实现 |
| R5 | 基本衣服导入 | 支持上衣、裤子、鞋，录入名称、照片、品牌、主色、备注 | 衣橱页添加衣物 | 已实现 |
| R6 | 上衣、裤子和鞋的组合效果 | 组合页按三类选择衣物并生成纵向预览 | 组合页选择衣物 | 已实现 |
| R7 | 记录次数必须调用相机拍照 | 记录入口使用 `getUserMedia` 打开相机，拍照后才可保存 | 记录页“打开相机/拍照识别/保存”流程 | 已实现 |
| R8 | 记录前确定日期是否为当天 | 记录日期默认本地当天，非当天时禁用保存并提示 | 修改日期为非当天 | 已实现 |
| R9 | 自动识别是哪件衣服 | 导入照片生成本地特征，拍照后按类别生成候选和置信度 | 拍照识别后查看候选 | 已实现 |
| R10 | 一次性交付方案设计、编码、自测、push | README、设计文档、单元测试、构建验证、远程推送 | 文档和 CI 可执行命令 | 已实现 |

## 非目标

| 编号 | 内容 | 原因 |
| --- | --- | --- |
| N1 | 云端账号、多设备同步 | 首版先做本地优先，避免后端与隐私成本 |
| N2 | 深度学习级服装识别 | 首版无训练集，先用可运行的本地视觉特征算法 |
| N3 | 非当天补录 | 用户明确强调记录次数必须拍照并确定当天，首版强制当天 |
